# Open-source combinator catalogue

Every open-source project Lens links to, bridges, rebuilds light, or learns from. One row per project, ranked by score (see [COMBINATOR.md §4](../brain/COMBINATOR.md#4-how-a-project-comes-in-the-four-modes)). The twice-weekly combinator scan keeps it current on branch `research/combinator`; the monthly review promotes rows into dossiers.

Columns: **Mode** is Link, Bridge, Rewrite light or Learn. **Score** is 0–100 (blank until scored). **Status** is Discovered, Catalogued, Proposed, Dossier, Built, or Shipped. **Agent hooks** names the intents, controls and MCP tools that exist or are planned.

Seeded on 26 November 2026 from the Lens Apps catalogue (`catalog/apps/catalog.json`, 52 apps). Those rows are all Link mode and still need scores, so the first scans will score them.
