# Combinator

The working files for [the combinator plan](../brain/COMBINATOR.md):

- [CATALOG.md](CATALOG.md): the ranked table of every open-source project Lens links, bridges, rebuilds or learns from.
- `scan/YYYY-MM-DD.md`: one report per scan run (twice weekly, Monday and Thursday).
- `ARCHIVE.md`: rows retired from the catalogue (created when needed).
- `CREDITS.json`: generated from the catalogue; feeds the site's Credits Wall and the in-app Credits page (planned, H0).

The scan proposes; people decide. Nothing in these files is merged into the app automatically.
