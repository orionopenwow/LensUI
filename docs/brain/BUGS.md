# Bugs

Bug hunt of `main` at `5a4a5b2`, 22 November 2026. Severity: **Critical** (data loss, security hole, user stuck), **High** (broken promise, safety gap, residue after uninstall), **Medium** (wrong behaviour with a workaround), **Low** (polish). "Owner" names the branch or PR that owns the file when another agent is working on it; those were not touched.

Method: pattern greps (`generated/patterns.md`, rerun with `node tools/brain/refresh.mjs`), then reading the risky paths by hand: Remove all Lens changes, folder icons, every file deletion in Rust, hook installation, mutexes in window procedures, agent safety wiring, approval UI. Tests after the fixes: `bun test src` → 630 pass, 0 fail. Fable wave 1 (23 November 2026) closed B-04, B-05, B-06 and B-13; see their rows below. Rust tests were added for every Rust fix; this workspace has no crate cache or network, so `cargo test` runs in CI (Windows build job) on the PR.
