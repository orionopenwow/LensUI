## 1. Top 5 ideas to build

### 1. Dock hover card: "Titles list" mode for windows (and more than four windows)
- **Evidence:** Windows 11 Experimental build 26340.10013 (16 Nov) adds a taskbar setting under Personalization › Taskbar › Taskbar behaviors that lists open windows by title instead of thumbnails ([Windows Insider blog](https://blogs.windows.com/windows-insider/2026/11/16/announcing-new-builds-for-16-november-2026/), [Windows Mode](https://www.windowsmode.com/windows-11-insider-builds-november-16-2026/)).
- **Why it matters:** Microsoft is shipping this because thumbnails are slow and unreadable once an app has many windows. Lens's hover card caps at four thumbnail tiles, so a browser or Explorer with ten windows is not fully reachable from the dock. A list is also cheaper (no DWM thumbnails), which helps low-end GPUs.
- **Lens status:** **Partial.** `src/components/DockPreviewStrip.tsx` shows live DWM thumbnails with `MAX_TILES = 4`, falling back to icon + title only for windows it cannot preview. There is no list mode and no setting.
- **Effort / risk:** S / low. Pure UI plus one setting; list mode skips the DWM thumbnail registration entirely.
- **Files likely touched:** `src/components/DockPreviewStrip.tsx`, `src/surfaces/DockSurface.tsx`, `src/surfaces/DockSurface.css`, the Dock & Top Bar settings card, `src-tauri/src/config.rs` (new `dock.previewMode: "thumbnails" | "list" | "auto"`), `src-tauri/src/win_previews.rs` (skip registration in list mode), `src/types/generated.ts`.

### 2. Lens MCP server: expose Shelf, clipboard history and dock pins to Claude (gated)
- **Evidence:** Raycast for Windows 2.13 (18 Nov) ships a local MCP server so Claude, Cursor and others can read clipboard history, snippets, quicklinks and browser tabs, with one-click setup for Claude Desktop ([Raycast changelog](https://www.raycast.com/changelog/windows/2-13)). Windows' taskbar agents are reported to connect through MCP ([Windows Latest](https://www.windowslatest.com/2026/04/18/microsoft-confirms-ai-agents-are-still-coming-to-the-windows-11-taskbar-as-it-prepares-for-public-rollout/); Microsoft docs not checked).
- **Why it matters:** Raycast is the closest launcher rival and now makes "my desktop is a tool for Claude" a headline feature. Lens already has the better story (approval card, agent safety) but its MCP surface is window, theme and system only.
- **Lens status:** **Partial.** `src-tauri/src/win_mcp.rs` already speaks MCP `2026-07-28` (stateless, `server/discover`) plus legacy `initialize`, and exposes `list_windows`, `focus_window`, `tile_windows`, `apply_theme_pack`, `set_volume`, `set_brightness`, `toggle_night_light`, `switch_workspace`, `search`, `run_action`, `get_action_status`. No Shelf, clipboard or dock-pin tools or resources.
- **Effort / risk:** M / medium (privacy). Clipboard items must go through the Needs-your-OK grant, the agent-safety hidden-text filter and the Shelf redaction rules; read-only first, with `add_to_shelf` as the only write. AGENTS.md §3.3 applies: never return stored secrets.
- **Files likely touched:** `src-tauri/src/win_mcp.rs`, `src-tauri/src/shelf/*`, `src-tauri/src/clip/*` (or `win_clipboard.rs`), `src-tauri/src/control/grants.rs`, `src-tauri/src/agentsafe/*`, `docs/MCP.md`, `src/components/AgentsPane.tsx`.

### 3. Dock app groups that open as a workspace
- **Evidence:** Stardock Start11 v3 preview (6 Nov) adds "Taskbar Islands", Alt-drag to group apps, groups pinned as workspaces, and a button for recently closed apps ([AlternativeTo](https://alternativeto.net/news/2026/11/stardock-announces-start11-v3-with-start-menu-widgets-taskbar-grouping-and-layout-sharing/)). The Windhawk "Taskbar reorder within/between groups" mod (Jan 2026, still the newest Ramen post) shows steady demand for group control ([Ramen Software](https://ramensoftware.com/news)).
- **Why it matters:** Lens has Islands and workspaces as separate features. Joining them ("drop Figma onto Slack to make a Design group; click the group to launch both into Workspace 2") is a differentiator Start11 is about to sell for $10.
- **Lens status:** **Partial.** Islands dock style exists (`src/dock/islands/*`), drag-to-reorder pins exists (`reorderPinnedIds` in `src/surfaces/DockSurface.tsx`), workspaces exist (`src-tauri/src/win_workspaces.rs`). No user-defined groups, no "launch group" action.
- **Effort / risk:** M–L / medium. `DockSurface.tsx` is a 2.5k-line hotspot (see B-15), so land the data model and the island rendering separately.
- **Files likely touched:** `src/surfaces/DockSurface.tsx`, `src/dock/islands/layout.ts`, `src/dock/islands/IslandParts.tsx`, `src-tauri/src/config.rs`, `src-tauri/src/win_workspaces.rs`, `src-tauri/src/commands/dock.rs`, `docs/DOCK_STYLES.md`.

### 4. Scroll on a dock icon to change that app's volume
- **Evidence:** Windhawk's "Taskbar Volume Control Per-App" mod (scroll over a taskbar button to change that app's volume) keeps being cited as a must-have ([Windows Central](https://www.windowscentral.com/microsoft/windows-11/i-wish-this-windows-11-feature-didnt-require-a-mod-microsoft-is-slacking); article dated Jan 2026, page served under a different headline).
- **Why it matters:** Cheap, delightful, and it shows the dock is "smarter than the taskbar" in a 2-second demo.
- **Lens status:** **Partial.** Per-app audio sessions are already read and set in `src-tauri/src/win_quick_settings.rs` (used by `src/settings/pages/SoundPage.tsx` and Quick Settings). The dock has no wheel handler.
- **Effort / risk:** S / low. Needs a modifier option (plain wheel vs Ctrl+wheel) so it doesn't fight dock scrolling in long docks, and a tiny volume pill above the icon.
- **Files likely touched:** `src/surfaces/DockSurface.tsx`, `src/surfaces/DockSurface.css`, `src-tauri/src/win_quick_settings.rs`, `src-tauri/src/commands/dock.rs`, `src/types/generated.ts`, Dock options card.

### 5. Show Claude/Lens agent progress on the dock
- **Evidence:** Windows' taskbar agents show progress when you hover the Copilot icon and are opening to third-party agents, off by default ([Windows Latest, Apr 2026](https://www.windowslatest.com/2026/04/18/microsoft-confirms-ai-agents-are-still-coming-to-the-windows-11-taskbar-as-it-prepares-for-public-rollout/)). Raycast 2.11 added "Send Window to AI" (4 Nov) ([Raycast changelog](https://raycast.com/changelog/windows)).
- **Why it matters:** Lens Presence already shows an overlay and banner while Claude acts, but once you look away there's no ambient "still working / needs your OK / done" signal where your eyes go. A ring on the dock's Ask icon, plus the pending-approval count, closes that gap.
- **Lens status:** **Partial.** `src/presence/model.ts` tracks runs; dock badges exist for notifications and core apps (`lens://coreapp-badge` in `DockSurface.tsx`); `src/dock/ai/DropToAi.tsx` has its own progress. No unified agent-progress ring.
- **Effort / risk:** S–M / low. Read-only UI on events that already exist.
- **Files likely touched:** `src/presence/model.ts`, `src/surfaces/DockSurface.tsx`, `src/dock/ai/aiDock.css`, `src/approval/PendingPill.tsx` (share the count), `src-tauri/src/presence/*` (emit a compact progress event).
