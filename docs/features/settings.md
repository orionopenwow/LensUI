## Rundown

Settings is the one window where everything in Lens is changed. It opens from the Dock gear (always on Quick settings since #89), docked to the Dock or free-floating, with a Simple mode (the fun, common settings) and Advanced mode (every page and card). It is backed by one settings writer, a registry that also feeds search, the Guide and the hyper test inventory, and a control catalogue that agents and Command use.

- **Who it's for:** everyone; Simple mode for most people, Advanced for power users and testers.
- **Front end:** `src/surfaces/ControlCenterSurface.tsx` (1,385 lines: shell, tab routing, several inline pages incl. Top Bar), `src/settings/SettingsNav.tsx` (sidebar, search, mode pill), `src/settings/registry.ts` (23 pages, sections, controls, keywords), `src/settings/search.ts`, `src/settings/pages/*.tsx` (18 page files), `src/settings/simple/*` (ModePill, SimpleView, MoreOptions), `src/settings/ui/*` (primitives, FillSlider, ErrorBoundary), `src/themeux/{ThemeTab,DockTab}.tsx`.
- **Data:** `src/hooks/useLensState.ts` (`updateConfig`), `src-tauri/src/config.rs` (`write_config_file` — the single writer: atomic temp+rename, refuses settings Lens couldn't load back), `src/control/catalogue.json` (generated by `cargo test export_catalogue`), `src/guide/index.json` (generated by `tools/guide/build-index.mjs`).
- **Tests:** `settingsHub.test.ts`, `settings-simple.test.ts`, `search.test.ts`, `guide.test.ts`, `shortcuts.test.ts`, `fillSlider.test.ts`, `src-tauri/src/tests/config_writer.rs` (no other writer), `control::tests::export_catalogue`; perf `settings-tab-switch`; `tools/robust/theme-switch.mjs`; `tools/hyper` (every page, row and catalogue setting; failures listed in `tools/hyper/known.json`); visual goldens `tools/parity/golden/settings-*`.

## Polish assessment
- **Motion:** theme switches apply in one frame (#88); page switching has no transition; a 120 ms opacity cross-fade on the page body would make tab changes feel intentional without layout cost.
- **Copy:** older inline sections in `ControlCenterSurface.tsx` (Top Bar, parts of Desktop) use Title Case and long descriptions; newer pages are plain sentence case.
- **Visual parity:** 24 settings goldens; the Simple view and the About page's new Magic (preview) section have none.
- **A11y:** switches named (B-16); search has a label; the mode pill is a radiogroup. Focus order after switching page lands on the sidebar, not the page heading.
- **Perf:** `settings-tab-switch` at ~0.7 long tasks per tab (#75) with a 50 ms p95 baseline (#97); first open of Appearance was 230 ms before #75.
- **Consistency:** inline pages in `ControlCenterSurface.tsx` vs page files — two patterns.

## One idea to push to main
**"Recently changed" strip at the top of Quick settings**: the last five settings the person (or an agent) changed, each with Undo. Data: the single writer already knows the diff; keep a small ring buffer in `%APPDATA%\LensUI\settings-history.json` (local). Makes agent changes visible and reversible from the place people look.

## Test plan
**Unit:** registry integrity (every page has label, icon, ≤4 hero controls — exists), search ranking table (20 queries → expected first hit), Simple view only shows allowed rows, undo snapshot for theme choices restores every key, mode pill state persists.
**Rust:** config writer refuses unloadable JSON, one writer test, catalogue export stable, damaged-value repair per type.
**Headless / parity:** golden for every page × light/dark (add Simple view, About Magic preview); `tools/robust/theme-switch.mjs` full matrix nightly; frame sampling on page switch (no flash).
**Windows E2E:** `control-center` scenario plus: open from gear lands on Quick; second press closes; dragged-off Settings isn't auto-closed; Ctrl+F search → Enter → scrolls to a section; a setting saved survives restart.
**Hyper:** every catalogue setting set/verify/restore; every Guide row clickable (B-40/41 fixed → remove from `known.json`).
**Owner's PC checklist:**
1. Gear → Quick settings; change Dark/Light, accent, Night light.
2. Ctrl+F "taskbar" → Enter.
3. Switch to Advanced; visit each page once; nothing jumps or flashes.
4. Pick a theme pack, then the original — folder colours return.
5. Rebind the Command shortcut in the cheat sheet; try a clash.
6. About › Report a problem — preview shows no personal paths.
7. Drag Settings off the Dock; it stays open when you move away.
