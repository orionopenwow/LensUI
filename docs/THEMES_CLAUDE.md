# Claude Code community themes in Lens

Lens ships **59 community theme packs** from the Claude Code ecosystem, in the Theme gallery under **Browse all › Claude Code**. Every card credits its author and has an **Original ↗** link.

All of these are **unofficial** in Lens: Lens copies only colour values (palettes are facts), never artwork, backdrop code, logos or the Claude wordmark. Anthropic's example themes are Apache-2.0; every community source below is MIT.

How a pack is built:
- **Surface:** the theme's background, or, for Anthropic's scene themes, the theme's own *glass tint* (the colour the app lays over the scene).
- **Accent:** read from the palette file, or for scene themes the scene's signature colour ("palette derived from the scene").
- **Animated backdrops** are not copied. Where a theme has one, the pack suggests the closest Lens Playground scene and links the original.
- **Contrast:** every pack meets the 4.5:1 body-text bar as published, so no pack needed a contrast lift (lowest: Catppuccin Frappé at 11.8:1).

### Not imported, and why
- **Claude Code's built-in `/theme` set** (dark, light, daltonized, ANSI): Claude Code isn't open source and publishes no palette file. The unofficial *Claude Dark/Light/Dusk/Midnight* ports and the colour-blind-safe *Daltonized* packs above cover the same ground.
- **`claude-theme` on npm** (Claude Light/Dark, rust `#C15F3C`): it overlaps with the Claude Code VS Code ports already imported, so it is listed rather than duplicated.
- **Lens built-ins:** Catppuccin Mocha, Tokyo Night, Nord, Dracula, Gruvbox dark, Rosé Pine, Solarized dark and Everforest dark already ship in Lens, so their matcra587 terminal versions were not added again.

## For maintainers
- Packs live in `src/themes/community/claude.ts`, with ids prefixed `cc-`. `COMMUNITY_PACKS` in `src/themes/packs.ts` keeps them apart from the 18 built-ins.
- Schema additions (optional, backward-compatible): `collection`, `source { name, author, url, license }`, `inspiredBy`, `backdrop { scene, note, url }`, and tier `"Community"`.
- Tests: `src/__tests__/communityThemes.test.ts`. Screenshots: `node tools/parity/build.mjs && node tools/parity/community/shoot.mjs`.
