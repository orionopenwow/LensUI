## Connect your browser
show: settings:ai:Browser extension

Install the Lens browser extension, then use Install bridge in Settings › AI & Command › Connections. The extension never talks to the internet; it only talks to Lens on this PC.

## Right-click on a page
anchor: browser

Select text or right-click a page, link, image or video and open the Lens menu: Summarise, Explain, Translate, Rewrite, Extract, Add to Shelf, Copy as Markdown, Transcribe video.

## Add File Explorer actions
show: settings:ai:File Explorer right-click

Turn on File Explorer right-click for Ask, Summarise, Add to Shelf and Copy path into context. On Windows 11 they sit under "Show more options". Turning it off removes only what Lens added.
