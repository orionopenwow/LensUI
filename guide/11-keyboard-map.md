## Open things
show: palette

Alt+Space opens the palette. The Windows key opens the Lens Launcher when Shell keys are on. Ctrl+Alt+Space opens Lens Command (tap once for Mini).

## The Dock
show: dock

With a Dock icon focused (Alt+Space, then Tab, or after a click), the arrow keys move along the Dock and typing a name finds an app. The arrow that points into the screen opens that app's windows: Up and Down choose, Enter switches, Delete closes one, Esc goes back. Alt+1–9 opens the first nine apps when that shortcut is on.

## Windows
show: settings:system:Drag Windows

Hold Alt and drag to move a window; Alt+right-drag to resize. In Overview, Shift+←/→ or Shift+1–9 moves the selected window to another workspace.

## Pointer and effects
show: settings:theme:Mouse pointer

Ctrl+Shift+F8 toggles the pointer spotlight when pointer effects are on.

## Everywhere
show: guide

Esc always steps back one level. Ask the Guide "what's the shortcut for…" any time.
